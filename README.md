# 银行认购预测

通过客户信息、营销记录和宏观经济指标，预测客户是否认购定期存款（`y`）。以下结果整理自三份 Notebook 的代码与已保存输出，未重新训练模型。

## 数据分析结果

[简要分析.ipynb](简要分析.ipynb) 使用 `data/bank-additional-full.csv`，共 **41,188 条记录、21 列**（含目标变量）。

- 未检测到空值，但有 **12 条重复记录**；原 Notebook 中“没有重复值”的描述与输出不一致，后续代码也未去重。类别中的 `unknown` 仍作为独立类别保留。
- 未认购客户 36,548 人，认购客户 4,640 人，正类占 **11.27%**。类别明显不平衡，因此主要关注正类 F1 和 PR-AUC。
- 探索分析显示，学生、退休客户的认购率相对较高；住房贷款、个人贷款类别间未见明显区别。违约记录为 `yes` 的样本仅 3 条，难以据此概括规律。
- 历史营销结果、联系次数及是否曾联系与认购率有关；月份间存在差异，星期之间变化较小。这些是样本内关联，不代表因果关系。
- 通话时长 `duration` 与目标变量的相关系数约为 **0.4053**，但联系前无法获取，因此后续建模将其删除。
- 宏观指标存在较强相关性，例如 `emp.var.rate` 与 `euribor3m` 的相关系数约为 **0.9722**；后续仍保留这些指标参与建模。

## 特征工程结果

[特征工程.ipynb](特征工程.ipynb) 生成两个版本，均保留全部 41,188 条记录。

| 版本 | 处理方式 | 输出 |
| --- | --- | --- |
| 基础特征 | 删除 `duration`；目标变量转为 0/1；职业、婚姻、教育、贷款、联系方式、月份等类别变量独热编码（`drop_first=True`） | `data/processed_data_base1.csv`：52 个特征及目标列，共 53 列 |
| 增强特征 | 在基础版本上，对 `campaign`、`previous` 做 `log1p` 变换；用 `pre_contact` 替代 `pdays`；年龄分箱并独热编码，删除原始年龄 | `data/processed_data1.csv`：56 个特征及目标列，共 57 列 |

`pdays=999` 表示此前未联系，共 39,673 条；曾联系的记录为 1,515 条。增强版本只保留是否曾联系，不保留距上次联系的天数。年龄分组为 ≤25、26–35、36–45、46–55、56–65、>65 岁。

## 建模与评估结果

[建模预测.ipynb](建模预测.ipynb) 按 **80%/20% 分层划分**训练集和测试集，固定 `random_state=42`，训练阶段采用五折交叉验证。测试集共 8,238 条，其中正类 928 条、负类 7,310 条。逻辑回归采用标准化与平衡类别权重，XGBoost、LightGBM 使用正类权重处理类别不平衡。

以下为测试集结果。基线使用基础特征，其余模型使用增强特征。

| 模型 | Accuracy | 正类 Precision | 正类 Recall | 正类 F1 | 加权 F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基线逻辑回归 | 0.8348 | 0.3671 | 0.6444 | 0.4677 | 0.8533 |
| 特征工程后逻辑回归 | 0.8342 | 0.3665 | 0.6476 | 0.4681 | 0.8529 |
| XGBoost | 0.8460 | 0.3898 | 0.6498 | 0.4873 | 0.8618 |
| LightGBM | 0.8541 | 0.4082 | 0.6562 | 0.5033 | 0.8682 |
| 最终优化 LightGBM | 0.8823 | 约 0.48 | 约 0.60 | **0.5328** | **0.8876** |

最终模型的 Precision、Recall 取自保留两位小数的分类报告，其余数值取自保存的对比表。

### LightGBM 优化

以正类 F1 为目标，使用 `RandomizedSearchCV` 搜索 50 组参数，每组进行五折交叉验证，最优交叉验证 F1 为 **0.4993**。随后通过训练集折外预测，在 0.10–0.90 范围内以 0.01 为步长选择阈值，最终选中 **0.50**。

主要最优参数：`n_estimators=1200`、`learning_rate=0.05`、`num_leaves=7`、`min_child_samples=40`、`colsample_bytree=0.85`、`reg_lambda=1.0`、`scale_pos_weight≈3.9383`。

| 指标 | 原始 LightGBM | 最终优化 LightGBM |
| --- | ---: | ---: |
| 正类 F1 | 0.5033 | 0.5328 |
| 正类 PR-AUC（average precision） | 0.4955 | 0.4878 |
| 加权 F1 | 0.8682 | 0.8876 |
