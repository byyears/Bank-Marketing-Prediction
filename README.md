# 银行营销分析与定期存款认购预测

基于 41,188 条银行营销记录，分析客户特征、历史互动与认购行为的关系，并构建定期存款认购预测模型，为客群分层和营销策略提供分析线索。

## 分析流程

- [简要分析.ipynb](简要分析.ipynb)：检查数据质量与类别分布，从客户画像、经济属性、营销互动、触达时间和宏观环境等维度比较认购率。
- [特征工程.ipynb](特征工程.ipynb)：剔除联系前无法获得的通话时长，完成类别编码、联系次数对数变换、历史联系标记及年龄分箱。
- [建模预测.ipynb](建模预测.ipynb)：对比逻辑回归、XGBoost 和 LightGBM，通过分层抽样、交叉验证及参数搜索评估模型效果。

## 主要发现与业务启示

**认购记录占比仅为 11.27%，需要重点识别潜在认购群体。** 单看准确率容易掩盖类别不平衡，因此使用正类 F1 和 AP（average precision）评估识别与排序能力。

**客户群体之间存在认购率差异。** 学生和退休群体的样本认购率分别约为 31.4% 和 25.2%，高于总体水平，可作为分层触达实验的候选客群；实际策略仍需结合客群规模与触达成本评估。

**历史互动具有较强的区分信息。** 历史营销成功组的样本认购率约为 65.1%，可进一步测试基于历史互动的客群运营策略。联系次数、渠道和月份也存在差异，但不能据此推断因果关系或直接确定最佳触达频次。

**分析过程中兼顾信息可用性与结果可靠性。** duration 为通话结束后才可获得的信息，因此在联系前预测中剔除；pdays=999 单独识别为此前未联系。违约记录为 yes 的样本仅 3 条，不据此推广结论。

## 模型结果

采用 80%/20% 分层划分和五折交叉验证。优化后的 **LightGBM 正类 F1 达到 0.5328**，较基线逻辑回归相对提升约 **13.9%**，改善了对潜在认购记录的识别效果。以上数值来自 Notebook 已保存的评估结果。

模型优化以正类 F1 为目标，并结合 AP 检查排序质量。
